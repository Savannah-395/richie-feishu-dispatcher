# project-template

Use this folder as a template for a business project repository. Push the finished project as its own GitHub repo beside `richie-feishu-dispatcher`.

## Scope

Describe what this project owns, what data or systems it may touch, and when richie should use this project's skills.

## Skills

- `_template`: Copy this skill folder and replace it with real workflow instructions.

## Notes

- This project should be its own GitHub repo so permissions can be managed per project.
- richie will clone or pull this repo into a local folder beside the dispatcher.
- Keep project-specific references under this project folder.
- Put shared workflow logic in each skill's `SKILL.md`.
- Prefer explicit project/skill names in Feishu prompts.
